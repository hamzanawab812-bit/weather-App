# 🌦️ Weather App

A responsive Weather App built using HTML, CSS, and JavaScript. It uses the OpenWeather API to display real-time weather information for different cities.

## ✨ Features

- Search weather by city name
- Display temperature in Celsius
- Show humidity and wind speed
- Change weather icons according to conditions
- Responsive design for mobile and desktop
- Display an error message for invalid city names

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- OpenWeather API

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Enter a city name to check its weather.
